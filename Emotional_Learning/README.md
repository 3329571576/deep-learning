### 内容

手机游戏现在是一个巨大的市场，尤其是在中国。监督客户的评论是预测游戏商业潜力的主要方式。

手游网站 TapTap 上约 300 款游戏的标签评论，可用于情感分析的应用，共4888个数据示例。

该数据集的评论来自著名的手机游戏 App TapTap。用户评论低于 3 星（最多 5 星）被视为 0（不满意），其他为 1（满意）。这两个类别的比例大约是五十比五十。

该数据集主要用于探索中文NLP的应用。例如，当一个新游戏发布时，人们会在微博、游戏论坛、贴吧等上讨论它。创建特定模型以识别玩家讨论趋势的自动化过程将有助于决策。


### 数据注释
* review：评论文本
* sentiment：0代表不满意，1代表满意。
